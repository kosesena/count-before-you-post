Count Before You Post

AI agents are getting write access to real systems, and they trust the document. This one can't write a number into the ERP until a camera has counted it.

Muse Spark: reads the note, looks, runs the agent SAM 3.1: counts and outlines every carton Muse Voice Transcribe: the receiver's count Muse Code: wrote the ERPNext client Muse Image: drew the cast

Six deliveries at the dock

A receiving dock rendered in Blender. Pick a delivery to see what each model read, which rule of the gate decided, and what the Spark agent did. Every number here comes from a recorded run against the real Meta Model API and a real ERPNext.

The receiver's own count

Muse Voice Transcribe writes down what the receiver says; Spark pulls out the number and whether they were sure. An unsure receiver, or a number the camera doesn't confirm, goes to a human. (Synthetic Turkish voice; real recordings are next.)

The cast

Characters: Sena's concepts, drawn with Muse Image. Fan-made, not official Meta mascots.
