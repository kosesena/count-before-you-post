What ran in these examples?

Voice, the second note reader and Wonder's pre-write audit are not established by these historical core recordings. Their separate experiments and the newer full-workflow trials are available in the development evidence.
Where the other Meta models contribute
  • Voice: transcribes speaker turns so the receiver's count can be distinguished from the driver's claim.
  • Spark Open: independently rereads the note before a full-workflow approval.
  • Wonder: audits the note reading; separately drafts discrepancy and supervisor paperwork.
  • Muse Code: built parts of the project and attempted writes as an external agent through the same MCP gate.
  • Muse Image: created the character artwork used to explain these roles.
These roles describe the wider project, not additional checks silently credited to the three recordings above.
